# REBOUND RAVINE (HACKATHON)


How to play the game?

It is a simple platformer game. Press the start button at the Main Menu to teleport to a world full of adventure. Get your way out of the ravine you have found yourself stuck in.

Use arrow keys to move around
-left arrow -left
-right arrow -right
-up arrow -jump

In the air you unlock special moves
-B to bounce midair (Less reliable directions)
-A and D to dash while moving midair
-S to downslam (No use but it looks cool)

Sadly you must reload the page when you fall (Sorry)
